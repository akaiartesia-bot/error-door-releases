# 错误的门 · 官方安装包

这里仅发布“错误的门”的签名安装包与更新清单，不包含程序源码、授权签名私钥、邮箱配置或分发记录。

- Windows 10/11 x64：在 [v5.11 发布页](https://github.com/akaiartesia-bot/error-door-releases/releases/tag/v5.11) 下载 `error-door-v5.11-windows-x64.zip`，完整解压后运行“错误的门.exe”。
- macOS Intel / Apple 芯片（Rosetta）：下载 `error-door-v5.11-macos-x64.zip`，解压后将 App 放入“应用程序”。首次打开请右键 App，选择“打开”。

版本信息与安装包哈希位于 `latest.json`；应用会在自动安装前验证制作人的 RSA 签名与 SHA-256。
